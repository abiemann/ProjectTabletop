# Gallery lettering

`Smokum-Regular.ttf` is the unmodified Smokum typeface by Brian J. Bonislawsky
(Astigmatic), downloaded from the official
[Google Fonts repository](https://github.com/google/fonts/tree/main/apache/smokum)
on 2026-10-26. It is bundled for the Target Practice middle-cover messages.
The font is loaded from the app's assets; it does not require system installation.
Its narrow, contrasting strokes preserve the Western style with a lighter
appearance. Messages use the regular weight without an added outline.
