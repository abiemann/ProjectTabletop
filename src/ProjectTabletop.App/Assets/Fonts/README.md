# Gallery lettering

`Rye-Regular.ttf` is the unmodified Rye typeface by Sorkin Type Co,
downloaded from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/rye)
on 2026-10-26. It is bundled for the Target Practice middle-cover messages.
The font is loaded from the app's assets; it does not require system installation.
