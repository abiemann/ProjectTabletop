# Empty gold DEAL control fixture

The expected image contains app-generated Blackjack artwork. The camera image
preserves its actual projector and webcam colour response at 1920 × 1080, without
resizing or changing the recorded RGB within the controls and their independent
static reference patches. The paired JSON preserves the native mapping and masks.
Only these generated board regions and a narrow registration margin remain;
every unrelated camera pixel is black. No hand, object, room or user artwork is
included.

The September 28, 2026 source frame shows crisp, unobstructed DEAL lettering.
The old readable-caption exception nevertheless measured more than 7% changed
control area and accepted it as foreground after two fresh observations. This
fixture checks that a unique gold panel's optical colour response cannot trigger
hand-acquisition illumination merely because another button's text is readable.
