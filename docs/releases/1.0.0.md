# Project Tabletop 1.0.0

The first downloadable Windows release of Project Tabletop: a local camera-and-projector tabletop with Dragon Slots, Photo Copy, Blackjack, Paint, Crown & Deed, Globe and Vice Royale Roulette.

## Download and install

Download **ProjectTabletop-1.0.0-win-x64-setup.exe** from the assets below. It targets Windows 11 x64 and includes .NET, the Windows App SDK, native C++ dependencies, hand models and artwork. It installs for your account without administrator rights and creates a Start menu shortcut. The optional local-control MCP executable is included in the `ControlMcp` subfolder.

The setup is unsigned; Windows may display an unknown-publisher warning. `SHA256SUMS.txt` records the release asset hashes, and the JSON manifest identifies the source commit and installed payload. Source archives are separate from the installer. Existing settings, saved games and exported pictures survive uninstall.

## Included behavior

- Shared calibration, native-resolution board rendering, palm-down hand tracking, sideways-index/pinch selection and caption-based long presses.
- Seven boards, local Crown & Deed save/resume, Photo Copy transparent PNG and Swirl exports, Paint image exports, and virtual-credit casino games.
- Local diagnostic logging and MJPEG recordings in the Hand-Tracking tester; inference and captured camera frames remain on the PC.
- A project license page in setup and a Licenses button in Settings for reading project and third-party terms.
- Windows CI with locked dependencies, offline regression groups, version/model/artwork/payload checks, and an installation/startup/navigation/render/uninstall smoke test before publication.
