# Project Tabletop 1.3.1

This maintenance release improves object and marker tracking, restores unresponsive controls, and prevents unwanted search spotlights.

## Fixes

- **Photo Copy:** a thin optical fringe around an illuminated object no longer repeatedly releases and reacquires its light. The detector allows a bounded two-pixel fringe in its rectified analysis image while retaining the original body, edge, movement, removal and nearby-object checks. Captured outlines, holes, transparency and image colours are unchanged.
- **Football:** improved double-bar detection when a marker trained in brighter conditions blends into dark turf or sits near white goal markings. The fallback retains the learned geometry and projected-artwork safeguards; stale-input timeouts are unchanged.
- **Globe:** intact navigation-arrow lettering clears stale hold evidence, allowing the visible buttons to respond without first hiding and restoring them with a swipe.
- **Shared search spotlights:** disabled captions cannot trigger a search light. This prevents controls disabled during Roulette's wheel animation from causing unwanted illumination, while active controls retain normal hand acquisition.
- **Blackjack:** EXIT accepts a deliberate caption hold when the reaching arm also crosses the lower betting controls. The crossed wager controls remain inactive until released.

## Download and install

Download **ProjectTabletop-1.3.1-win-x64-setup.exe** from the release assets. It targets Windows 11 x64 and includes .NET, the Windows App SDK, native dependencies, hand models, artwork and sounds. Setup installs for the current account without administrator rights. Updates preserve settings, saved games, learned marker profiles and exported pictures.

The installer is unsigned. `SHA256SUMS.txt` contains the asset hashes, and the JSON payload manifest identifies the source commit and packaged files. The source archives are separate from the installer. See the [installation guide](https://github.com/abiemann/ProjectTabletop/blob/v1.3.1/docs/INSTALL.md) and [1.3.0 feature notes](https://github.com/abiemann/ProjectTabletop/blob/v1.3.0/docs/releases/1.3.0.md).

## Validation and limits

The release source passed **688 offline tests with no skips**.

The Photo Copy correction passed eight focused offline test groups, the full object-regression console suite and four native application checks covering actions, gestures, the drawer and acquisition. Debug and Release builds completed without warnings or errors. Recorded-camera replay retained all **31 illuminated-card frames** and rejected all **22 removed-card frames**. The user confirmed that the corrected live build keeps the light steady on the card and turns it off after removal. Movement, nearby objects, washed-out objects and real holes are covered by the regression checks.

The updated Football tracking was reported approximately 99% reliable in the development-tabletop movement check. Blackjack EXIT passed its live check without changing the wager. Roulette's corrected spinning-wheel behavior is covered by native checks; its physical retest remains pending. These results apply to the tested setup; lighting, camera and projector differences can still require adjustment.

The Windows pipeline runs the full offline suite and verifies installer creation, installation, startup, board navigation, GPU preview rendering, shutdown and uninstall before publication. Hosted packaging checks do not replace physical camera/projector acceptance. Remaining validation limits are recorded in the [README](https://github.com/abiemann/ProjectTabletop/blob/v1.3.1/README.md).
